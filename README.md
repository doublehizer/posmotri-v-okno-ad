# Посмотри в окно

Проектная работа 2 спринта курса «Веб-разработчик» Яндекс Практикума.

Приложение показывает видео «вида из окна» в разных городах. Можно искать видео по городу и времени суток, переключать ролики кликом по карточкам и подгружать новые карточки кнопкой «Показать еще».

В этой работе свёрстаны стили приложения по макету в Figma: раскладка на Flexbox, кастомные чекбоксы на псевдоэлементах, состояния `:hover`, `:active` и `:focus-visible`, обрезка текста и позиционирование прелоадеров.

## Технологии

- HTML5
- CSS3 (Flexbox, псевдоэлементы, `object-fit`, `line-clamp`, `:has()`)
- JavaScript (логика приложения из заготовки)
